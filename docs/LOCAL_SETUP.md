# 在本机运行 ATC2.0

下载整个仓库并完整解压，进入 `local/`。该目录包含同一套游戏及两种系统的启动器，不需要分别下载平台压缩包。

| 系统 | 启动入口 |
| --- | --- |
| Apple Silicon / Intel Mac | `ATC_Launcher_macOS.command` |
| Windows 11 x64 | `ATC_Launcher_Windows11.bat` |

首次启动需要网络与足够的磁盘空间。启动器会创建独立 Python 环境，安装依赖，再下载 SenseVoice、Kokoro 与 Qwen 的模型文件，加载完成后自动打开 `http://127.0.0.1:18765/game`。启动器窗口需要在游玩时保持打开。

不需要预先安装 Node.js 或编程工具。首次安装模型和依赖可能较慢，电脑性能、网络以及下载站点的可达性都会影响时间。Qwen 权重下载支持断点续传，失败后可以重新运行启动器。模型准备完毕后，游戏语音从本机运行，不调用在线合成、浏览器播报或系统声音作为替代。

## 设置声音

在游戏设置中选择中文或英文，再分别给管制员、飞行员选择音色。中文默认使用 Qwen，英文默认使用 Kokoro，也可明确选择 Qwen 音色。选择会按中英文记忆。每个角色可调整语速，并试听电台声音或纯净声音。

Windows ARM、全新 Windows 设备与 Intel Mac 的首次安装没有覆盖所有实机组合，遇到问题欢迎附系统版本和启动器错误信息反馈。Mac 安全设置可能要求确认运行下载的启动器，请确认代码来源后按系统提示处理。

## 常见情况

- **页面未打开**：先看终端是否仍在下载、安装或加载。服务就绪后也可手动访问上面的地址。
- **提示端口被占用**：关闭之前的游戏启动器，避免连接旧后台，再重新运行。
- **听不到声音**：先检查全局静音、角色播报开关、系统输出设备与音色选择。
- **识别失败**：允许浏览器麦克风权限，选中航班，按住 Shift 说完整指令后再松开。也可以先用按钮或文字体验。
- **下载失败**：检查终端提示、网络与剩余空间，然后重试；不必手动删除已有模型。

Windows 安装日志位于 `local/.atc_windows_logs/`，Qwen 加载日志位于 `local/.atc_logs/`。反馈前请留意去除自己的代理账号等私人信息。

## 不安装模型，只预览网页版

浏览器版不需要 Python 或模型。开发者安装 Node.js 后，在仓库根目录执行 `npm ci && npm run build && npm run preview`，打开终端显示的 localhost 地址。

正式分享可以部署生成的 `dist/` 到静态网站。麦克风需在 HTTPS 或 localhost 下使用；浏览器识别是否可用取决于浏览器与网络。
