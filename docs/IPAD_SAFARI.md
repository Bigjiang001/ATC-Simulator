# iPad Safari 在线版适配

在雷达空白处单指拖动可平移；双指张开或合拢可缩放雷达，两指中点对应的空域保持在手指下面。缩放范围为 55%–280%，原有加减与居中按钮继续可用。雷达区域通过非被动触控监听和 touch-action 阻止网页缩放；其他页面区域保留浏览器手势。双指开始时取消尚未提交的飞机引导，全部手指抬起后才能开始下一次单指操作；系统取消触控也不会发送指令。

在线版使用 Safari 提供的系统语音。补充识别 Li-mu、Yun Yang、Siri male 标识以及 Aaron、Evan、Nathan、Oliver 等男声名称；实际选项只显示设备当前提供的声音，不伪造不存在的音色。自动模式在每次播报时重新匹配，避免系统声音稍后加载时仍使用首次女声回退。手动选择优先，音调保持原声。

如果设置提示未检测到男声，可前往 iPad 设置 → 辅助功能 → 朗读与语音（旧版本为朗读内容）→ 声音，下载所需语言男声，再返回游戏设置点击“刷新系统音色”并试听。Safari 可能不会暴露所有下载的声音；网页无法强制安装或提供 Safari 未开放的音色。没有男声时仍使用当前语言可用的声音，并明确提示。

验证命令：npm run typecheck、npm test、npm run build、npm run test:ui、npm --prefix online run test:ipad。触控测试在 Chromium 的移动触控模拟环境覆盖 1366×1024 横屏和 1024×1366 竖屏，检查双指缩放、中心锚点、网页比例、平移、取消和防误发指令。语音测试使用模拟 Safari 声音列表及延迟加载，不能替代实体 iPad 的声音试听。本次未连接实体 iPad。
