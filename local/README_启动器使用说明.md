# ATC2.0 本地语音与双平台启动器

双击同目录的 `ATC_Launcher_macOS.command` 或 `ATC_Launcher_Windows11.bat`。启动器会补齐独立环境和模型，等待模型加载及预热完成，再自动打开当前目录的 ATC2.0 网页。游戏期间保持启动器窗口打开。

- 中文合成：Qwen3-TTS-12Hz-0.6B-CustomVoice，默认普通话，可选全部九种音色：Vivian、Serena、Uncle_Fu、Dylan（北京话）、Eric（四川成都话）、Ryan/Aiden（原生英语）、Ono_Anna（原生日语）、Sohee（原生韩语）。这些是同一模型内置音色，无需另外下载权重。
- 英文合成：默认原有本地 Kokoro-82M，也可在音色列表中明确选择 Qwen 的音色；失败时不会在两者之间自动切换。
- 中英文语音识别：原有本地 SenseVoice Small。按住 Shift 说话，松开后识别并执行指令。
- 不调用在线语音、浏览器语音或 macOS/Windows 系统语音。合成失败保留双语通话文字并显示提示，不自动更换声音。

首次安装需要联网。新增中文模型在 Apple Silicon Mac 上使用同一 0.6B 模型的 MLX 8-bit 权重，下载约 2 GB；Windows 和 Intel Mac 使用官方 PyTorch 权重。下载支持断点恢复，失败后再次双击启动器即可。首次完成后模型从本地加载，游戏语音无需联网。纯 CPU 电脑的合成速度取决于硬件。

Qwen 使用 `.venv_atc_qwen`（Windows 为 `.venv_atc_qwen_windows`）独立环境，原有 SenseVoice、Kokoro 权重保留。新的中文缓存位于 `models/qwen3_tts_cache_v1`，不读取以前 `zh_tts_cache` 中的在线或系统音频。角色声音、语言和语速可在游戏设置中选择；界面语言与底部双语通话记录独立。

如果提示端口 18765 被旧服务占用，请关闭原启动器窗口再启动。新启动器会检查语音后端版本、三个模型状态及当前网页内容，避免误打开旧服务。Qwen 加载日志在 `.atc_logs/qwen-worker.log`；Windows 安装日志在 `.atc_windows_logs`。

项目目录可以包含中文和空格，也可以移动；启动器使用当前目录的绝对解释器和相对模型配置，不依赖虚拟环境的 activate 脚本。不要只复制启动器，请保留整个项目目录。

模型来源：
- https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice
- https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-0.6B-CustomVoice-8bit
- https://github.com/Blaizzy/mlx-audio

## 音色与语速（本轮更新）

在【设置】→【管制员语音 / 飞行员语音】中展开音色下拉列表。已移除旧版角色预设按钮；每个选项注明名字、原生语言或方言、性别与声音特点。下方还会显示当前音色说明。当前通话语言独立于音色原生语言，外语音色读中文可能带口音。

两位角色各自使用 0.90–1.50× 语速滑块。中文推荐 1.20×，英文默认 1.12×；【恢复推荐】可一键重置。选择按中英语言分别记忆，并自动保存在当前浏览器。语速改变的是音频播报时长，不代表推理等待时间同比缩短。

【电台试听】包含无线电滤波和所选底噪；【纯净试听】绕过这两项，便于对比模型音色。后端已把相位声码器变速换成语音 WSOLA 保音调变速，降低变速产生的相位拖尾风险；没有人为加入房间混响。模型原音自身可能仍带音色相关的空间感，不能把算法调整等同于专业去混响。

更新后请关闭旧启动器，再重新双击启动器并刷新页面，让新版后端与网页一起加载。启动器会补齐小型 audiotsm 依赖，不必重新下载 Qwen 模型。旧缓存保留，但新版不会复用旧变速结果。
